# Interview guide

*The interview is where [being known](../career/being-known.md) and [being picked](../career/career-traits.md) meet: a showing of the abilities, the traits, and the difference you have made. Everything in this repo has an Interview lens for that reason; this folder holds what cuts across them.*

Cross-cutting interview material. Stage-specific questions live in the [workflow page](../workflow.md); ability-specific behavioural questions live in `competencies/`. This folder holds the things that don't belong to one stage.

| File | What it is |
|---|---|
| `product-sense-cases.md` | Worked product-sense / metric / business cases, each with a strong answer and common weak answers |
| `sql-practice.md` | SQL patterns that come up in analyst interviews, with worked solutions |
| `experimentation-questions.md` | A/B testing and causal-inference questions, with worked answers |
| `behavioural-story-bank-template.md` | STAR template, tagged by ability, with the prompts to prepare |
