# The six abilities (+ working with AI)

The [matrix](../README.md#2--abilities-by-stage-the-matrix) says *where* each ability is exercised; these files say *what* it is. Every file follows the same structure, so once you have read one you know how to read the rest:

definition and why it matters · where it shows up in the workflow · **the toolkit** (concepts and frameworks, each with the question it answers and the stage where an analyst uses it) · how it looks in practice · what good looks like by level · interview lens · resources

| Ability | In one line | Primary in stages |
|---|---|---|
| [Technical craft](technical-craft.md) | The data platform, SQL, statistics, experiments, causal designs, machine learning and model evaluation, deep learning and LLMs, charts — each concept defined, with the detail that matters and the trap | 4, 5 |
| [Analytical reasoning](analytical-reasoning.md) | Structuring ambiguity, hypotheses, method choice, causal thinking, judging a result | 2, 3, 5, 6 |
| [Business acumen](business-acumen.md) | The four-sentence quick read of any business or unit; how the money works; placing the question against the goal; sizing findings | 1, 2, 3, 6, 7, 8 |
| [Communication](communication.md) | Answer-first structure, audience, charts, difficult news, handling challenge | 7 |
| [Collaboration & influence](collaboration.md) | Working with product, data engineering, engineering, and other analysts; getting decisions made without owning them | 1, 3, 4, 7, 8 |
| [Ownership & delivery](ownership-and-delivery.md) | Prioritising, time-boxing, managing up, following through, leaving things reusable | 8 |
| [Working with AI](working-with-ai.md) | Delegating tasks to agents, verifying what comes back, evaluating whether an agent is fit for a kind of work | cross-cutting |

The junior / mid / senior tables in each file are the detail behind the four [phases](../phases/).

What sits around the abilities — finding your own work, the dispositions, career capital — is in [career/](../career/).
